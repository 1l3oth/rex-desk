# Khmer words for Rex Desk

Written with real Khmer software as the reference, not machine translation: Android's own Khmer (Settings, System UI, Contacts,
Calendar, Email, Package installer; about 8,400 English-Khmer pairs), Firefox's Khmer, and the Mozilla Khmer team's style guide.
When Android used more than one word, the most frequent one is used here. A native speaker should read the screens and change any
word that sounds wrong; change it once in `public/i18n/km.json` and in this table.

## Rules

- Everyday words are Khmer. Brands and developer words stay in Latin letters, because Cambodian developers say them that way:
  Rex Desk, Claude, Codex, Gemini, GitHub, MCP, API key, token, terminal, branch, commit, push, pull request, worktree.
- Numbers stay 0-9. Full stop is `។`. Quotes stay straight. No zero-width spaces: the browser breaks Khmer lines by itself.
- "You" is អ្នក. Commands are the bare verb, with no polite particle, like Android.
- Khmer has no plural: one sentence serves "1 file" and "3 files".
