# Security

## Report a problem

Please report security problems privately through [GitHub security advisories](https://github.com/1l3oth/rex-desk/security/advisories/new), not in a public issue. Say what you found, how to reproduce it, and which version you use (Settings → About).

The maintainer, Vong Pichdaraboth, answers within a few days. A fix ships in a new release, and the advisory is published once people can update.

## Supported versions

Only the latest release gets fixes. Installed apps update themselves; see Settings → Backup and updates.

## Signed files

How Rex Desk's installers are signed, and how to check a signature, is in [docs/CODE-SIGNING.md](docs/CODE-SIGNING.md).
